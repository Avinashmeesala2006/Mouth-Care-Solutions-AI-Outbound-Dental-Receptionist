# Mouth Care Solutions - AI Phone Receptionist

FastAPI backend, **open-source Asterisk** telephony and a packaged **Fish Speech** voice cloned
from the clinic's reference recording (`fish-references/mouth-care-receptionist-reference-20260919.wav`),
plus a React/Vite web client and a no-build demo page at `/demo`.

> **Safety boundary:** callers only hear approved wording from `knowledge/clinic/approved.json`
> (rendered as `knowledge/clinic/voice_prompts.json`). Prices, doctors, insurance, durations,
> holidays and diagnoses are never invented: such questions become callback requests, and
> appointment requests are recorded for the clinic team to confirm, never auto-booked.

## How a call works

```
POST /api/calls/request -> allow-list + rate limit + fresh preflight -> AMI Originate
Asterisk -> SIP trunk or GSM modem -> phone network -> callee answers
dialplan -> FastAGI (this app) -> STREAM FILE <verified Fish asset> -> RECORD FILE -> faster-whisper
        -> grounded phone agent -> next prompts ... -> HANGUP
AMI events (ringing, answered, hangup cause) -> durable call record + evidence trail
```

Details and setup: [docs/telephony-asterisk.md](docs/telephony-asterisk.md). Asterisk alone cannot
reach the phone network: a SIP/PSTN trunk or a GSM/4G modem with a SIM is required, and until one
is registered `GET /api/telephony/preflight` reports `LIVE_CALL_ALLOWED=false` with the exact blocker.

## Voice pack

Calls play pre-generated audio, never synchronous CPU TTS and never a generic TTS voice.
Regenerate with the running Fish Speech server (`127.0.0.1:8080`):

```powershell
E:\fish-speech\.venv\Scripts\python.exe scripts/generate_voice_pack_http.py --publish
python scripts/validate_voice_pack.py
```

Every asset is reference-conditioned, converted to 8 kHz mono PCM and verified acoustically
(rejects tones/silence) and by a faster-whisper transcript (keywords, required phrases such as the
approved emergency wording, no stutters). The pack is published atomically only when every asset
passes, and the backend re-validates it before any asset is played.

## Run (Windows)

```powershell
.\scripts\setup_asterisk.ps1          # once WSL2 + Ubuntu are installed
.\scripts\run_local_stack.ps1         # Fish :8080, FastAPI :8000, optional ngrok for the web app
.\scripts\asterisk_ctl.ps1 status     # Asterisk + live-call readiness
```

## Configuration

Copy `.env.example` to `.env` (never commit it). Live mode: `APP_MODE=live`, `MOCK_MODE=false`,
`CALL_PROVIDER=asterisk`, `FISH_SPEECH_ENABLED=true`, `ASTERISK_AMI_SECRET` (generated by the
setup script), `OUTBOUND_ALLOWED_DESTINATIONS`, and the phone line (`TELEPHONY_INTERFACE`,
`SIP_TRUNK_*` or `GSM_DEVICE`, `OUTBOUND_CALLER_ID`). `GET /ready` lists configuration errors.

## Development

```bash
pip install -r backend/requirements.txt
pytest backend/tests -q
cd frontend && npm install && npm test && npm run build
python scripts/zero_error_scan.py
```

Demo mode (`MOCK_MODE=true`) never places calls. Live appointment scheduling stays disabled
until a production booking repository is connected. Historical Twilio-era material is in
`docs/archive/`.
